# Development

Initialize recursive submodules and use the [platform build commands](build.md). CTest exercises core formats and conversions, database namespace cleanup and reload, and native memory validation. Run the pinned open.mp integration workload for changes to native registration, ownership, packaging or Pawn scripts.

Use tabs for indentation in C++ and Pawn. YAML uses spaces. The project builds with warnings as errors by default. Keep the status enum, native table and public include consistent. Maintain immutable file mappings and keep native entry points on the server thread.

Use the [benchmark harness](../benchmarks/README.md) for latency and memory changes, and identify the commit, toolchain and database inputs in any results.
